# 🍃 LeafSnap Mini – Plant/Animal Identifier 🌿

A Python Tkinter GUI app that allows users to **upload an image of a plant or animal** and predicts the top 3 classes using a **pre-trained MobileNetV2 model**.

## Features
- Sleek **black aesthetic GUI** with neon highlights
- Upload images from your computer
- Displays the image and top 3 predictions
- Optional GIF/doodle for a fun look
- Beginner-friendly Python project

## How to Run
1. Clone the repo:
git clone https://github.com/fatimaimran-123/LeafSnapMini.git

2. Install dependencies:
pip install -r requirements.txt

3. Run the GUI:
python leafsnap_gui_aesthetic.py

4. Click **Upload Image** and select a plant or animal photo.

## Libraries Used
- TensorFlow & Keras
- Pillow
- NumPy
- Tkinter (built-in)
